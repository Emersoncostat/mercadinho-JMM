# Mercadinho
PROJETO de Avaliação da Segunda VA do Professor IGOR MEDEIROS ;
desenvolvido para a disciplina de Programação Orientada a Objetos da UFAPE.

O sistema tem como objetivo realizar o gerenciamento de um mercado utilizando conceitos de orientação a objetos e arquitetura em camadas.
