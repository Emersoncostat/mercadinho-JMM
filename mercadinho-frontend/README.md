# Frontend — Mercadinho JMM

Interface em Next.js com catálogo público e área administrativa.

## Executar

Com o backend disponível em `http://localhost:8082`:

```powershell
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Acesso inicial

- E-mail: `admin@mercadinhojmm.com`
- Senha: `admin123`

Esses dados podem ser alterados pelas variáveis `ADMIN_EMAIL` e `ADMIN_PASSWORD` ao iniciar o backend.
